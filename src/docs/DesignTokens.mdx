# Design Tokens

Every token below is read out of the Figma library **"Solutions Library- 2026"**
(file key `KihJKyGA20stc2SSjAlxYU`) via the Figma MCP, for **both** colour modes:

- light — `UI Components — Light Mode` (node `24146:44359`)
- dark — `UI Components — Dark Mode` (node `24148:4298`)

They live in `src/theme/tokens.ts`, which is the only place in the library allowed to contain a
raw colour. Everything else references them through the Mantine theme or a `--sds-*` CSS variable.

Use the **Color scheme** control in the toolbar to switch modes — the swatches on this page react
to it.

## Brand

`Brand/Primary/*` and the related action/CTA blues, ordered lightest to darkest to satisfy
Mantine's ten-shade contract. Index 6 is `Brand/Primary/Primary` and is the theme's
`primaryColor` / `primaryShade`; it is the same value in both modes.

<Story of={DesignTokens.Brand} />

## Neutral

Figma's `Neutral/01`–`Neutral/10`. This ramp **inverts between modes** — in light it runs
near-white to near-black, in dark it runs the other way. It is registered as a Mantine
[`virtualColor`](https://mantine.dev/theming/colors/), so `c="neutral.5"` means the same thing
visually in either mode.

`Neutral/00` is pure white in both modes and is exposed as `theme.white` rather than a ramp entry.

<Story of={DesignTokens.Neutral} />

## Semantic surfaces

Mode-dependent values that aren't colour ramps — text, card surfaces, the glass treatment, tab
gradients. These are emitted as `--sds-*` CSS variables through the theme's
`cssVariablesResolver`, so they flip automatically with `data-mantine-color-scheme`.

<Story of={DesignTokens.Semantic} />

## Spacing

Figma's `Spacing/*` and the `xsm | small | medium | large | xlg` size scale.

<Story of={DesignTokens.Spacing} />

## Radius

Figma's `Border Radius/*`. `Border Radius/Default` (10px) is the theme's `defaultRadius`, mapped
to the `lg` key.

<Story of={DesignTokens.Radius} />

## Type scale

Figma's `Paragraph/*` sizes. The family is **Source Sans 3** throughout, with **Manrope** for
label styles and **Source Code Pro** for code.

<Story of={DesignTokens.TypeScale} />

## Status and accent

`error`, `warning`, `success`, `info` and `accent` are registered as Mantine colours and flip
between modes, so `color="error"` works on any Mantine component. Figma publishes a single value
per status per mode rather than a full ramp, so these are flat tuples — no intermediate shades
have been invented. See the **Badge → Colors** story for them rendered side by side.
