# Design tokens

Every token below is extracted from the Figma **"Solutions Library- 2026"** library and wired into
`tailwind.config.ts` as a theme extension. Import them as values from `solutions-design-system`, or
use the Tailwind class shown in each table.

```tsx
import { brand, paragraph, spacing } from 'solutions-design-system'
```

## Typography

Four families are in use: `{fontFamily.sans}` for body and headings, `{fontFamily.label}` for
labels and badges, `{fontFamily.ui}` for dense UI, and `{fontFamily.code}` for code.
